# ELITE Zanzibar Website

Production-ready static website prepared for GitHub Pages.

## Intended GitHub Pages URL
https://naimahkunambi.github.io/elite-zanzibar/

## Deployment
This repository includes `.github/workflows/pages.yml` for GitHub Pages deployment from `main`.
After creating the repository, set **Settings → Pages → Source → GitHub Actions** once. Future pushes to `main` deploy automatically.

## Client configuration
Edit only `config/site-config.js` for domain, email, phone, WhatsApp, and social profiles.

## Journal management
See `BLOG_MANAGEMENT.md` and `content/articles.js`.
